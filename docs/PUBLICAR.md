# Clonar e contribuir

Repositório: https://github.com/ImmortalGOD23/supreme-octo-fiesta-free-llms

```bash
git clone --recurse-submodules https://github.com/ImmortalGOD23/supreme-octo-fiesta-free-llms.git super-fcc
cd super-fcc
python super-fcc.py init
python super-fcc.py install-fcc
```

Os segredos são gerados no computador de uso. Não envie `.runtime`, `.env`, bancos ou backups de chaves. Os cinco projetos upstream são referências Git públicas fixadas, com autoria e licenças originais preservadas.

Para enviar mudanças, use uma conta GitHub com permissão no repositório, crie uma branch e abra um pull request. Atualizações dos submódulos devem atualizar `upstreams.lock.json` e passar pelos testes de contrato.
